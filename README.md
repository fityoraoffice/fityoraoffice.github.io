### 📱 Detail Pembayaran QRIS

QRIS (Quick Response Code Indonesian Standard) memudahkan pembayaran dari **semua bank & e-wallet** dalam satu scan.

**Langkah bayar QRIS:**

1. 🛒 Pilih produk & lakukan checkout
2. 💳 Pilih metode **QRIS** di menu pembayaran
3. 📸 Screenshot / simpan gambar QR yang muncul
4. 📱 Buka aplikasi m-banking / e-wallet kamu
5. 🔍 Pilih menu **Scan QRIS** → upload gambar QR
6. ✅ Konfirmasi nominal & selesaikan pembayaran
7. ⚡ Sistem verifikasi otomatis dalam **< 10 detik**

**Bank & e-wallet yang support QRIS:**

| Bank | E-Wallet |
| :---: | :---: |
| BCA, BRI, Mandiri, BNI | DANA, OVO, GoPay, ShopeePay |
| CIMB, Permata, BTN | LinkAja, iSaku, Sakuku |
| Sinarmas, Danamon, OCBC | Jenius, Blu, SeaBank |
| Semua bank ber-logo QRIS | Semua e-wallet ber-logo QRIS |
